PLAYVERSE V9 — MANUAL STEPS

1. Extract this ZIP.
2. Replace the old files in your GitHub repository with everything from this folder.
3. Commit/push.
4. Render auto-deploys. Wait until it says Live.
5. Open your Render URL.

THAT IS ALL.

No room code.
No password.
No database.
No environment variables.
No persistent disk.

HOW TO PLAY WITH A FRIEND
- You open the site, enter your name, tap Create Room.
- Your friend opens the same site, enters their name, sees your name under Available rooms, and taps it.
- They join immediately.

INSTALL
- On supported Chrome, use the Install Game button when it appears.
- You can also use Chrome's Install app / Add to Home screen option.
