FAST MANUAL STEPS
=================

TO UPDATE YOUR CURRENT GAME
1. Extract this ZIP.
2. In your existing GitHub repo, replace the old project files with ALL files/folders from this ZIP.
3. Commit the changes.
4. Render redeploys automatically if the repo is already connected.
5. Wait until Render says Live.
6. Test: https://YOUR-URL/health
7. Game: https://YOUR-URL/
8. Admin: https://YOUR-URL/admin

NO EXTRA SETUP
- no database
- no admin password
- no environment variable
- no persistent disk
- no separate backend

DEFAULT SOUND
Sound is ON. Chrome unlocks audio after the first tap/click automatically.

ADD YOUR OWN PERMANENT STICKER
1. Upload PNG/JPG/WEBP into public/stickers/
2. Add an entry in data/stickers.json
3. Commit; Render redeploys.

PERMANENT RULE CHANGES
Edit data/settings.json and commit.

IMPORTANT
/admin has no password, so anyone who knows that URL can open it.
