FAST MANUAL STEPS
=================

FIRST PUBLISH
1. Upload ALL files/folders from this project to ONE GitHub repo.
2. Render > New > Blueprint.
3. Select the GitHub repo.
4. Deploy and wait until it says Live.
5. Test: https://YOUR-URL/health
6. Main game: https://YOUR-URL/
7. Admin: https://YOUR-URL/admin

YOU DO NOT NEED
- database
- admin password
- environment variable
- persistent disk

ADD A STICKER PERMANENTLY
1. Upload PNG/JPG/WEBP to public/stickers/
2. Add its entry in data/stickers.json
3. Commit. Render redeploys automatically.

CHANGE GAME RULES PERMANENTLY
Edit data/settings.json and commit.

IMPORTANT
/admin has no password, so anyone who knows that URL can open it.
