VOICE
Basic voice works with the included Google STUN servers and requires HTTPS in production.
For the most reliable voice across mobile networks / strict NAT, add these optional Render environment variables from a TURN provider:
- TURN_URLS
- TURN_USERNAME
- TURN_CREDENTIAL

No database is required. Chat history is in memory and resets if the server restarts.
