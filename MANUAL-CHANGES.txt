PLAYVERSE V10 — REQUIRED LIVE SETUP

1. Deploy this folder as a Node web service.
2. Connect PostgreSQL and set DATABASE_URL.
3. Set the real PUBLIC_BUSINESS_NAME, PUBLIC_SUPPORT_EMAIL,
   PUBLIC_SUPPORT_PHONE and PUBLIC_BUSINESS_ADDRESS.
4. Add Razorpay TEST Key ID, Key Secret and Webhook Secret.
5. In Razorpay, set webhook URL:
   https://YOUR-DOMAIN/api/payments/webhook
6. Enable payment.captured, payment.failed and order.paid.
7. Enable automatic payment capture.
8. Create a host account and complete one Razorpay test payment.
9. Confirm /health says database=persistent and payments=ready.
10. Submit the website and policy URLs to Razorpay.
11. After live approval, replace all TEST keys with LIVE keys.
