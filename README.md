# PlayVerse Premium V6

Multiplayer Snakes & Ladders, Tic Tac Toe and Word Search.

## Snakes & Ladders V6
- Rich classic wood/parchment board.
- Chess-style pawns, never dots.
- Detailed animated snakes and wooden ladders.
- Real 3D dice cube with dot/pip faces only.
- Smooth dice roll + landing animation.
- Server-locked turns: the opponent cannot roll until the current dice, pawn movement, snake slide or ladder climb is fully finished.
- Winner fires after the final movement finishes.

## Publish
Replace the files in the same GitHub repository and commit. Render can auto-deploy. No database, admin password, environment variable or persistent disk is required for the standard setup.
