PLAYVERSE V12

Main changes
- Exactly 10 clean, unique meme stickers.
- Larger general Word Search bank including MOUNTAIN, RIVER, FOREST, OCEAN and many more.
- Incoming chat preview appears above CHAT when chat is closed.
- Games and Players moved into a hidden ROOM drawer opened from the bottom-left button.
- SFX is always enabled; the SFX on/off button was removed.
- Live voice transport tuned for smaller audio chunks, ordered Socket.IO delivery, no compression, interactive AudioContext latency and click-reducing playback fades.
- V12 file names and a brand-new service-worker cache delete all older PlayVerse caches.

Run
1. npm install
2. npm start
3. Open the HTTPS deployed URL and allow microphone access.

Important
Microphone access requires HTTPS on normal deployed domains. localhost is also allowed by browsers for development.
